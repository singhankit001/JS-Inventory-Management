01Executive vision

Ten agents do the reading, matching and explaining. Head Office decides.

Jumpstart Inventory OS already runs every workflow from a Centre Leader's monthly request to Finance's payment, on demo data. This plan adds AI where language, documents and judgement slow people down, and keeps every spending approval, supplier choice, purchase authorisation and payment with a named person.

06Multi-agent orchestration architecture

An outbox, a job table and the state machines you already have

No agent framework. Domain events go into an outbox in the same transaction as the business write. A worker turns them into agent jobs, and every job moves through the existing AI_JOB machine.

07Technical stack and infrastructure

Keep the stack, add four things

The repository's choices hold up. AI needs a database, a speech-to-text service, object storage for media and a model provider behind the existing seam. Everything else is already there.

10Claude Code parallel agent strategy

Contracts first, then four lanes in separate worktrees

Parallel work only stays safe when the shared contracts are frozen before the lanes start. Each wave ends at a gate that the main session checks before merging.
